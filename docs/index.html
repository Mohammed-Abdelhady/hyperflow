Less orchestration. Better judgment.

A Markdown-only kernel for coding agents. Hyperflow chooses the smallest safe lane, uses extra agents only when independence matters, and keeps release and push under your control.

Get started Read the contract

Three lanes, fixed ceilings.

Direct

Clear, reversible, one subsystem. The coordinator executes with zero child agents.

Focused

One compact task file. Parallel workers only where work is independent, then one batch review.

Deep

Reserved for security, migrations, architecture, and research. Bounded investigation, specialist judgment.
